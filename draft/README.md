# Unused website images

168 unused loose image files were moved here from public/assets. Names and bytes are preserved; UNUSED_IMAGES.json records original paths and hashes for restoring them.

Usage was checked against all 241 current routes, CSS backgrounds, responsive image variants, metadata, active client scripts and optimized/poster dependencies. All 4,560 indexed packed images remain referenced and were kept. Fonts, videos, audit screenshots and source backups were not moved. This folder is outside public and is excluded from the staging deployment manifest.
